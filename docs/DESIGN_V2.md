# Design 2.0 — העלאת רמת העיצוב

**סטטוס: הושלם ✅** — כל 6 הפיצ'רים נבנו ונבדקו (בדיקות יחידה, e2e ו־axe על כל 16 הערכות).

מטרה: שהתפריט ייראה כמו עבודה של סטודיו גם בלי צלם ומעצב — באמצעות כותרות פתיחה דרמטיות, תמונות לקטגוריות, רקעים מעוצבים, ערכות ואפקטים חדשים, וכפתור "הפתיעו אותי".

## הנחות
- כל השינויים **תוספתיים** לסכמה (שדות אופציונליים עם ברירת מחדל) — תפריטים קיימים וגיבויי JSON ממשיכים לעבוד, `schemaVersion` נשאר 1.
- כל אפקט חדש: CSS/JS קל, מכבד `prefers-reduced-motion` ואת כפתור "הפחתת תנועה", לא מהבהב (WCAG 2.3.1), ונבדק ב־axe.
- ערכות חדשות חייבות לעבור את בדיקת הניגודיות האוטומטית (4.5:1).

## מה נבנה

| # | פיצ'ר | פירוט |
|---|---|---|
| 1 | **סגנונות כותרת פתיחה (Hero)** | `classic` (נוכחי) · `overlay` — הכותרת על תמונת שער במסך מלא עם מסך כהה הדרגתי · `split` — תמונה לצד הכותרת במסכים רחבים |
| 2 | **תמונת באנר לקטגוריה** | `section.image` — באנר רחב עם כותרת הקטגוריה מעליו |
| 3 | **רקעים מעוצבים (Patterns)** | ללא · נקודות · רשת · גלים · טרצו · ארבסקה · קווים אלכסוניים — CSS בלבד, בצבעי הערכה, ללא קבצים |
| 4 | **4 ערכות חדשות** | Art Deco אמרלד · בוטני · ברוטליסטי · שקיעה |
| 5 | **4 אפקטים חדשים** | זרקור עוקב־עכבר · בוקה (אורות מרחפים) · מסגרת גרדיאנט מסתובבת · קן ברנס (זום איטי בתמונות) |
| 6 | **"הפתיעו אותי"** | בחירה אקראית של שילוב מעוצב (ערכה + פריסה + רקע + אפקטים), עם Undo |

## קבצים שישתנו
`core/schema.ts`, `core/themes.ts`, `renderer/MenuRenderer.tsx`, `renderer/menuRuntime.js`, `styles/menu.css`, `editor/panels/DesignPanel.tsx`, `editor/panels/ContentPanel.tsx`, `i18n/ui.ts`, בדיקות.

## סיכונים
- אפקטים כבדים על מכשירים חלשים → כולם CSS עם `transform/opacity` בלבד; זרקור רק עם עכבר.
- ניגודיות טקסט מעל תמונה ב־overlay → מסך כהה הדרגתי קבוע + צל טקסט, נבדק ב־axe.
