# ניהול צוות בממשק

> **סטטוס: הושלם ✅** · ממשיך את שלב 2ב ([`PHASE2.md`](PHASE2.md)).

## מטרה
בעלים מנהלים את הצוות מהעורך, בלי API ובלי שורת פקודה:
- הזמנה של עורכים וצופים;
- שינוי תפקיד;
- השבתה והחזרה של משתמש;
- שליחת הזמנה מחדש.

## מסך `#/team` (בעלים בלבד)
- **כניסה למסך:** קישור "ניהול צוות" במקטע הענן, שמוצג רק לבעלים.
- **רשימה:** לכל משתמש מוצגים שם, אימייל, תפקיד, מצב (פעיל/מושבת) ותאריך הצטרפות. המשתמש המחובר מסומן "(אתם)".
- **הזמנה:** אימייל, שם (לא חובה) ותפקיד.
  - בלי ספק אימייל: מוצג קישור הזמנה חד־פעמי עם "העתקה", כדי לשלוח אותו ידנית. הקישור תקף 24 שעות.
  - עם ספק אימייל: מוצגת הודעה "ההזמנה נשלחה".
- **שינוי תפקיד:** בחירה מתוך רשימה, ומיד שמירה.
- **השבתה:** עם אישור. ההשבתה מנתקת מיד את כל הסשנים של המשתמש. אפשר להחזיר אותו בכל רגע.
- **שליחת הזמנה מחדש:** למשתמשים פעילים.

## אבטחה
- **ההרשאה נאכפת בשרת** (`requireRole('owner')`). הסתרת המסך מעורך או מצופה היא רק נוחות.
- השרת לא מאפשר להשאיר את העסק בלי בעלים פעיל (409 `last_owner`). הממשק מציג הודעה ברורה.
- קישור ההזמנה מוצג פעם אחת בלבד: הוא לא נשמר בדפדפן ולא נרשם בלוג.

## נגישות
- טבלה סמנטית עם כותרות.
- לכל שליטה תווית ייחודית שכוללת את שם המשתמש. כך קורא מסך מודיע, למשל, "תפקיד של dana@example.com" ולא סתם "תפקיד".
- הודעות סטטוס ב־`aria-live`.
- תמיכה מלאה ב־RTL.

## בדיקות

  - ניסיון להוריד את הבעלים האחרון;
  - עורך שנכנס לכתובת המסך;
